# Pricing and licensing

weekship is MIT licensed. Nothing in the code is gated, and you can run it on a repository or an organization for free.

The positioning:

- **One repository: free.** Run the CLI or the GitHub Action on a single repo as often as you like.
- **A whole organization: the team plan.** Running across every repo, on a schedule, with history and delivery to the owner is the work teams pay for.

The hosted team plan is not built yet. This page records the intent so nobody mistakes the open-source CLI for a trial.
